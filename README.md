# Emoji Game

A responsive memory game built with React where players must click each emoji only once before the timer expires.

## Features
- 🎮 Memory-based gameplay
- ⏱ Countdown timer
- 🏆 Live top score tracking
- 🔀 Dynamic emoji shuffling
- 📱 Responsive UI
- ⚛ Built with React Hooks

## Tech Stack
- ReactJS
- HTML5
- CSS3

## Installation

npm install
npm start
